# Are hybrid ensembles explained as faithfully as the single model they replace?

Code, dated protocols, cross-validation folds and per-fold results for the paper
*"Are Hybrid Ensembles Explained as Faithfully as the Single Model They Replace? Evidence from Eight Healthcare Datasets"*
(R. Kamboj, K. Kaur, A. S. Bhuyan, Chandigarh University).

**Everything is in the folder [`xai-hybrid-ensemble-faithfulness/`](xai-hybrid-ensemble-faithfulness/)**. Start with its
[README](xai-hybrid-ensemble-faithfulness/README.md), which maps every study in the paper to its protocol, script and results.
